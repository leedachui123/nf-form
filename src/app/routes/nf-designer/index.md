# 动态表单可视化设计器

本模块提供一个动态表单可视化设计器，用户可以通过按钮操作，调整表单字段及结构；可以通过属性菜单，编辑字段属性；可以在界面上实时查看表单效果，同时展示预览表单的用户输入。

## 主要组件

- **NfPreviewer**：表单预览组件，实时展示当前表单设计效果。
- **NfStructor**：表单结构组件，显示表单的字段层级关系，支持拖拽调整结构。
- **NfEditer**：表单编辑器组件，提供字段添加、删除、排序等功能。

## 布局说明

设计器采用三栏布局，左侧为表单预览区域，中间为表单结构区域，右侧为表单编辑区域。各区域均可独立操作，实时同步更新表单设计状态。

- 布局组件
    **NfPannel**: 用于包裹各个功能组件，提供统一的样式和布局支持。
