# 动态表单结构设计器

本模块提供一个动态表单结构设计器，通过列表管理表单字段，用户可以方便地添加、删除和配置表单字段的属性和验证规则。设计器界面分为三个主要部分：

- **添加字段按钮** 位于组件顶部，用户可以通过点击按钮添加新的表单字段。

- **字段列表面板** 位于组件主要部分，显示当前表单中的所有字段。用户可以通过拖拽调整字段的顺序，点击字段尾部的按钮可以修改字段名称，或删除字段。不要在这个组件里做任何字段属性的修改。

## 字段列表详细设计

1. 可拖拽排序
    - 使用 Angular CDK 的拖拽模块实现字段列表的拖拽排序功能。
    - 用户可以通过拖拽字段项来调整字段的顺序，排序结果会实时反映在表单结构中。

2. 字段重命名
    - 每个字段项尾部提供一个重命名按钮，点击后弹出输入框，允许用户修改字段对应的Property, 是该字段在表单中的唯一标识，不作为表单属性使用。

3. 字段删除
    - 每个字段项尾部提供一个删除按钮，点击后弹出确认对话框，确认后将该字段从表单结构中移除。

4. 字段显示
    使用以下形式展示字段列表，每个字段项显示字段名称和字段Key。列表中的每个字段对应一个可拖拽列表项，拖拽设计参考第一条用户可以通过拖拽调整字段顺序。
    列表项整体为左中右三段式布局：
    - 左侧：拖拽图标，提示用户可以拖拽排序。
    - 中间：字段名称和字段Key，字段名称支持点击编辑，字段Key为只读显示。
        > 展示区域一共分为两行：
            以Key作为一级标题，独占第一行显示
            以Name作为二级标题，与字段类型共占第二行显示

    - 右侧：重命名和删除按钮，分别用于修改字段名称和删除字段。

5. 样式设计
    - 字段列表采用简洁明了的设计风格，确保用户能够清晰地看到每个字段的信息和操作按钮。
    - 使用适当的间距和边框，使字段项之间的区分更加明显，提升用户体验。
    - 选中字段项时，应用高亮样式以提示用户当前操作的字段。
